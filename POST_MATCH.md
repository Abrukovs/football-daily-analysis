# Post-match журнал и ROI

`football_analysis.py daily` добавляет каждый опубликованный вариант в `post_match_journal.csv` со статусом `PENDING`. Исходный предматчевый отчёт не изменяется.

После завершения матчей подготовьте JSON с фактическими голами:

```json
[
  {"fixture_id": "ID_FROM_JOURNAL", "home_goals": 2, "away_goals": 1}
]
```

Затем выполните:

```bash
python3 football_analysis.py settle --results results.json
```

Скрипт заполнит `WON`/`LOST`, прибыль в единицах ставки и выведет:

- число рассчитанных ставок;
- число выигрышей и проигрышей;
- суммарную прибыль в units;
- ROI = прибыль / сумма рассчитанных ставок × 100%.

Для ML ничья считается проигрышем, поскольку методика разрешает только победу в основное время. Для ТБ 2,5 нужен минимум 3 гола, для ТМ 3,5 — максимум 3, для ОЗ «Да» гол каждой команды, для ОЗ «Нет» — ноль голов хотя бы одной команды.

До публикации ROI нужно добавить проверку фактических результатов из независимого источника и хранить источник и время получения результата. Не смешивайте разные версии линии: в журнале сохраняется коэффициент, зафиксированный при генерации отчёта.
