# Daily Football Analysis

Ежедневные предматчевые отчёты по футболу. Отчёты создаются автоматическим заданием в 05:00 по московскому времени и сохраняются в формате Markdown.

## Что находится в репозитории

- `daily_football_report_YYYY-MM-DD.md` — ежедневный отчёт;
- `current_findings_YYYY-MM-DD.md` — рабочие заметки отдельных дней, если они нужны для аудита;
- `METHODOLOGY.md` — подробное объяснение отбора исходов и причин отказа от ставки;
- `.gitignore` — список файлов, которые не следует отправлять в GitHub.

## Как скачать проект на другой сервер

1. Установите Git.
2. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/Abrukovs/football-daily-analysis.git
   cd football-daily-analysis
   ```

3. Откройте отчёты обычным редактором Markdown или текстовым редактором.

## Автоматическая отправка изменений

Скрипт `sync_to_github.sh` добавляет изменения, создаёт коммит и выполняет `git push origin main`:

```bash
./sync_to_github.sh
```

Ежедневное задание должно запускать этот скрипт после сохранения нового отчёта. Если вы меняете файлы вручную, запустите скрипт самостоятельно.

## Как вручную сохранить изменения

```bash
git add .
git commit -m "Обновить ежедневный отчёт"
git push
```

После настройки автоматизации ежедневный отчёт должен сохраняться и отправляться в GitHub автоматически. Перед использованием другого сервера проверьте расписание, часовой пояс `Europe/Moscow`, доступ к GitHub и источник коэффициентов.

## Важно о безопасности

В этот репозиторий нельзя добавлять токены, пароли, API-ключи, cookies браузера, файлы конфигурации Manus или приватные данные. Если на новом сервере нужны секреты, задавайте их через переменные окружения или защищённое хранилище секретов.

## Ограничения резервной копии

GitHub хранит копию файлов репозитория и истории изменений. Само расписание Manus, подключённые аккаунты, браузерные сессии и секреты не переносятся этим репозиторием автоматически. Их нужно настроить отдельно на новом сервере.
